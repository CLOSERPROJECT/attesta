# Org operator Draft lives in OrgSession; dirty-only client persist and Bozza chrome

**Draft** is in-progress Task working data before **Submission**—not Domain, not Worklist status, not entity **progress** (GLOSSARY **Draft**). The single writer is **OrgSession**: a client `drafts` map keyed by `draftKey` (`taskPath` + instance bag key), each entry `{ value, dirty }`. **seedDraft** hydrates from Load/Commit bundles without marking dirty; **setDraft** (operator or QR paths) sets **dirty** until **clearDraft** (successful Commit clears that address). Only **dirty** entries persist across reload and drive **Bozza** chrome; non-empty seed or schema defaults alone must not mark or write storage. Worklist stays the five-value server projection from [ADR-0005](0005-org-worklist-server-projection.md); **Bozza** is muted client chrome beside the existing status tag on act-now / overview rows when **hasDirtyDraft**—not a sixth `TaskStatus`, not `hasDraft` on Go projections. [ADR-0002](0002-affiliation-gated-stream-authoring.md) **draft/publish** is Formata stream catalog authoring—unrelated product law.

**Phase 1 persistence (reversible mechanism):** browser **localStorage** scoped by **org + userId + draftKey** (`attesta:org-draft:…`). Rehydrate into the in-memory map only when operator identity becomes known or **changes**—never rebuild from storage on same-identity **refreshKeepDrafts** (in-memory dirty wins). Persist dirty values with debounced writes and **flush on page hide**; v1 assumes a **single tab** (no `storage` event sync). **DraftPort** (server), multi-tab merge, and orphan key GC are **deferred**; a later ADR may supersede storage only without changing draft product law above.

**Considered options:** (1) **DraftStore** or per-form **DraftSession** beside OrgSession — rejected: dual writers and divergent clear/mark semantics. (2) **hasDraft** on Worklist / Go Load+Commit — rejected: draft is client-only until Commit; projections stay pure (ADR-0005). (3) Thread **StorageLike** through TaskForm / createConfigForm — rejected: persistence belongs at session boundary, not form factory. (4) Treat any non-empty bag as dirty — rejected: seed and defaults are not operator WIP. (5) **Bozza** as Worklist `draft` status — rejected: conflates chrome with Unlock/Submission/readyWhen law. (6) Rehydrate from localStorage on every Load refresh — rejected: clobbers unsynced in-memory dirty. (7) Server DraftPort in Phase 1 — rejected scope; seam stays client until product needs cross-device draft.

**Consequences:** SPA owns draft lifecycle (seed/set/clear, marks, storage adapter); Go and Worklist JSON unchanged for draft presence. QUnit/Playwright can inject **memoryStorage**. Operators see **Bozza** only after a dirty write; Commit success drops mark and storage for that key; identity switch flushes pending writes and resets the map (other users’ keys remain in localStorage). Follow-up ADRs may add **DraftPort**, multi-tab, or GC without reopening Session-as-source-of-truth or Worklist enum law.
